**Correction (2026-10-14):** the first Rev C report gave a workload dip of 258 mV and 221 mV for
the 10 ns step. Those runs had no transient max-step, so ngspice under-resolved the 10 ns load edges.
Every transient testbench now sets one (0.5–10 ns); the corrected values are in the tables above.

Also added in Rev C: **mixed-signal co-simulation**. `dvs_ctrl.sv` is compiled by Verilator and
runs inside ngspice through XSPICE `d_cosim` (`tb_ams_dvs_ctrl`). The real RTL ramps the code and
pre-boosts on the workload hint: 7 → 10 → 4, VOUT 1.226 → 1.315 → 1.142 V, burst dip 341 mV.

## Open issues (priority order)

1. **Hot, light-load regulation loss (pre-existing since Rev A/B).** At 125 °C with VIN = 1.98 V
   and load ≤ 100 µA (≤ 1 mA at fs), the leakage of the 700 µm pass device exceeds the 100 µA bleeder.
   Because the FVF clamps X below VOUT − Vsd(MC), the pass gate can't rise far enough to shut it
   off, and VOUT drifts up by 120–150 mV. Corner runs show this as wrapped PM (~390°), which
   `scripts/corner_summary.py` now flags as INVALID.
   An earlier Rev B report missed it: that summary only took the minimum PM.
   Rev D's smaller bleeder (40 µA) moves the onset in: PM is 25–47° at fs/ff, 125 °C, 1.8 V, light load.
   *Tried and rejected (Rev D study):* a fixed-shift source-follower gate buffer (X's 0.85 V window can't
   cover both "off" and "10 mA"); a longer-L pass device (0.5 / 0.7 µm: leakage barely improves, transient much worse);
   a bigger bleeder (80 µA only gives 33° at fs/125 °C).
   *Remaining fixes:* (a) an overvoltage **shunt clamp** (slow OTA, VOUT vs VREF + ~40 mV, drives an NMOS
   sink; costs only the leakage it absorbs); (b) a non-inverting **gain-stage gate driver**
   (Huang & Cheng, ICET 2023), which widens the gate range to VIN and raises loop gain (PSRR, line reg)
   but adds a pole.
2. **Overshoot at fast load release** is C_L-limited: VOUT peaks within the 10 ns edge, and the
   pass gate is already cut off in about 15 ns. The OBX pull-up gives only about 3 %.
   *Options:* more C_L in the remaining area, a direct output discharge clamp, workload-hint driven pre-bias.
3. **+12–15 mV DC offset** (MC/MR Vds mismatch + 5T OTA systematic offset).
4. **Iq ≈ 163 µA** after adaptive bias (Rev D). Remaining big items: OTA tail 40, bleeder 40, UB 30, reference 20.
5. PSRR / line regulation limited by the single-stage FVF (≈ 1/(g_mc·R_X)).
6. Ideal R/C still in `comp_rc`, `decap`, `rdac4`, `tr_boost` (Rb = 1 MΩ needs a pseudo-resistor).

## Next steps

1. Fix issue 1: shunt clamp first (smallest change), gain-stage driver as the alternative.
2. Use `dvs_ctrl.boost_en` (the workload hint) to raise the bias before bursts.
3. On-chip bias (beta multiplier) and VHI/VLO reference.
4. Real sky130 passives; Monte-Carlo mismatch on the dead zones and the replica.
5. Verilog-A behavioral models (OpenVAF/OSDI) for fast system-level sims; then layout → DRC/LVS/PEX → TT wrapper.
