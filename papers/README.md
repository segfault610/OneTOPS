# Papers

Put the PDFs from `docs/LITERATURE_SURVEY.md` here (this folder, `papers/`). Name them `<firstauthor><year>_<short>.pdf`,
e.g. `or2010_spike_detection.pdf`.

PDFs in this folder are git-ignored on purpose. Publisher copyright usually forbids
redistributing them, and the GitHub repo may be public. Keep notes in `notes.md` (tracked) instead.
